プログラミングの勉強目的で作ったやつです。
P2P地震情報から情報を取得しています。
HTMLとCSS、JSの勉強がしたかったのでお試しというか(笑)作ってみました。

-リンク-
https://scratch.mit.edu/projects/1378340663/

-画面の見方-
最新9件を表示します。
各カード上部に最大震度→発生時刻→震央地名→震源要素→津波の有無→各地点の震度
が表示されています。
また、タブレット・PCではカード右側に、スマホでは震源要素の下側に地図が表示されます。(画像7枚目参照)
-震度速報時について-
震度速報の場合は
発生時刻→最大震度→各震度
が表示されます。
-震源情報時について-
震源情報の場合は
発生時刻→震央地名→震源要素→津波の有無
が表示されます。
-情報が入っていない場合-
調査中や未入電・不明などと表示されます。
